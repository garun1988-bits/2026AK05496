## How each algorithm works (short explanation)

- **Logistic regression:** learns linear class boundaries using multinomial classification; standardized inputs improve optimization.
- **Decision tree:** splits on feature thresholds to form rules; scaling is generally unnecessary and deep trees can overfit.
- **KNN:** classifies from nearby training examples; scaling is important because distances depend on feature units.
- **Gaussian Naive Bayes:** estimates a Gaussian distribution per feature and class, assuming conditional independence.
- **SVM:** finds a separating boundary with an RBF kernel; scaling is important. `probability=True` enables probability-based AUC but increases fitting time.

All five models are fitted on the **same** training split and tested on the **same** held-out CSV. StandardScaler is inside the saved pipeline and is fitted **only on training data**, preventing leakage.

## Evaluation metrics and interpretation

| Metric | Meaning | Better direction |
|---|---|---|
| Accuracy | Correct predictions / all predictions | Higher |
| AUC | How well probability scores rank the correct class | Higher |
| Precision | Of predicted positives, proportion correct | Higher |
| Recall | Of actual positives, proportion recovered | Higher |
| F1 | Harmonic mean of precision and recall | Higher |
| MCC | Correlation of true and predicted labels | Higher |

For seven classes, the example uses **weighted** precision/recall/F1 and **weighted one-vs-rest** AUC, and multiclass MCC. The assignment does not mandate a multiclass convention, so explain the one you use. AUC must use probabilities (or appropriate continuous scores), not hard predicted class labels.
